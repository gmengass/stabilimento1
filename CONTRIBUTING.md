# Contributing

1. Pick or open an issue. Discuss larger changes first.
2. Branch from `main`: `feat/…`, `fix/…`, `docs/…`.
3. Use [Conventional Commits](https://www.conventionalcommits.org/).
4. Add tests for every change. Run the test and lint commands from `CLAUDE.md`.
5. Open a PR using the template. CI must pass and one review is required.
6. Don't commit secrets. Copy `.env.example` to `.env` locally.
